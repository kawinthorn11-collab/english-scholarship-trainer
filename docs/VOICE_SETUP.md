# ตั้งค่าเสียงพากย์ ElevenLabs ให้ครูหมูกับครูควาย

เว็บนี้ใช้เสียงจาก ElevenLabs แบบ **อัดเสียงไว้ล่วงหน้า** แล้วเก็บเป็นไฟล์ MP3 ในเว็บ
ทำให้เสียงเป็นธรรมชาติ โหลดเร็ว และ **ไม่ต้องใส่ API key ไว้ในหน้าเว็บ** (ถ้าใส่ไว้ในหน้าเว็บ ใครก็ขโมยไปใช้เครดิตของคุณได้)

บรรทัดไหนยังไม่ได้อัด เว็บจะใช้เสียงของเบราว์เซอร์แทนโดยอัตโนมัติ

## ขั้นที่ 1 · ใส่ API key เป็น Secret (ครั้งเดียว)

1. เข้า ElevenLabs → Profile → **API Keys** → สร้าง key ใหม่ (ให้สิทธิ์ Text to Speech)
2. เข้า repo บน GitHub → **Settings** → **Secrets and variables** → **Actions**
3. แท็บ **Secrets** → **New repository secret**
   - Name: `ELEVENLABS_API_KEY`
   - Secret: วาง key ที่ได้
4. กด **Add secret**

> ห้ามวาง API key ลงในโค้ด ในแชต หรือใน Issue เด็ดขาด

## ขั้นที่ 2 · เลือกเสียง (ไม่บังคับ)

ถ้าไม่ตั้ง จะใช้เสียงสำเร็จรูปของ ElevenLabs ให้ก่อน
อยากได้เสียงที่ชอบ ให้คัดลอก **Voice ID** จากหน้า Voices ของ ElevenLabs แล้วไปที่แท็บ **Variables** (ที่เดียวกับขั้นที่ 1) เพิ่ม:

| Name | ใส่อะไร |
| --- | --- |
| `ELEVENLABS_VOICE_PIG` | Voice ID ของครูหมูหวาน (แนะนำเสียงผู้หญิง สดใส) |
| `ELEVENLABS_VOICE_BUFFALO` | Voice ID ของครูควายขยัน (แนะนำเสียงผู้ชาย นุ่ม ทุ้ม) |
| `ELEVENLABS_MODEL` | ไม่ต้องใส่ก็ได้ ค่าเริ่มต้นคือ `eleven_v3` ซึ่งรองรับภาษาไทย |

เลือกเสียงที่พูดไทยได้ชัด ลองฟังในหน้า ElevenLabs ด้วยประโยคไทยก่อน

## ขั้นที่ 3 · สั่งอัดเสียง

1. เข้าแท็บ **Actions** ของ repo
2. เลือก **Generate voices (ElevenLabs)** ทางซ้าย
3. กด **Run workflow** แล้วเลือก
   - `core` = บทเรียน ทิป ข้อสอบแนวสากล บัตรคำศัพท์ (ประมาณ 18,000 ตัวอักษร) ← **แนะนำให้เริ่มที่นี่**
   - `all` = core + คำอธิบายข้อสอบจำลองทุกข้อ (ประมาณ 55,000 ตัวอักษร)
   - `limit` = จำนวนไฟล์สูงสุดต่อรอบ ใส่ `20` เพื่อลองฟังก่อนได้
4. รอประมาณ 5–20 นาที ระบบจะบันทึกไฟล์เสียงและอัปเดตเว็บให้เอง

รันซ้ำได้ ระบบจะอัดเฉพาะบรรทัดที่ยังไม่มีหรือเพิ่งแก้ไข ไม่เสียเครดิตซ้ำ

## ดูจำนวนตัวอักษรก่อนอัด (บนเครื่องตัวเอง)

```bash
npm run voices:check                       # core
node scripts/generateVoices.mjs --scope=all --dry-run
```

## ถ้ามีปัญหา

| อาการ | วิธีแก้ |
| --- | --- |
| Action ขึ้น `ELEVENLABS_API_KEY is not set` | ตรวจชื่อ Secret ให้ตรงทุกตัวอักษร |
| `HTTP 401` | API key ผิด หรือ key ไม่มีสิทธิ์ Text to Speech |
| `HTTP 400` เรื่อง model | ลองตั้ง Variable `ELEVENLABS_MODEL` เป็นโมเดลอื่นที่บัญชีของคุณใช้ได้ |
| เครดิตหมด | ใส่ `limit` ให้น้อยลง หรือเริ่มจาก `core` |
| ภาษาไทยออกเสียงแปลก | เปลี่ยน Voice ID เป็นเสียงที่รองรับภาษาไทยดีกว่า แล้วลบโฟลเดอร์ `public/audio` ก่อนรันใหม่ |
