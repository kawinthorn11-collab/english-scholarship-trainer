# ช่วยพัฒนาเว็บ MooKwai ได้ใน 10 นาที (ไม่ต้องเขียนโค้ด)

คู่มือนี้สำหรับ **อาจารย์ รุ่นพี่ และนักเรียน** ที่อยากช่วยเพิ่มหรือแก้เนื้อหาในเว็บ
ทำบนเว็บ GitHub ได้เลย ไม่ต้องติดตั้งโปรแกรม ใช้มือถือก็ได้ แต่คอมพิวเตอร์จะสะดวกกว่า

เมื่อส่งงานแล้วถูกนำขึ้นเว็บ ชื่อของคุณจะอยู่ในรายชื่อผู้ร่วมพัฒนา (Contributors) ของโปรเจกต์ตลอดไป

## ขั้นที่ 1 · สมัคร GitHub (ครั้งเดียว)

1. เข้า https://github.com/signup
2. ใส่อีเมล ตั้งรหัสผ่าน และตั้งชื่อผู้ใช้ (username)
3. ยืนยันอีเมลที่ GitHub ส่งไป

> ใช้บัญชีของตัวเองเท่านั้น หนึ่งคนหนึ่งบัญชี

## ขั้นที่ 2 · เลือกงานที่อยากช่วย

เปิดหน้า Issues: https://github.com/kawinthorn11-collab/english-scholarship-trainer/issues

งานที่ติดป้าย **good first issue** เหมาะสำหรับครั้งแรก เช่น

- เพิ่มบทเรียนหมูควาย 1 บท
- ตรวจเฉลยข้อสอบ
- แก้คำผิดหรือคำอธิบายที่งง

เขียนคอมเมนต์ใน Issue ว่า **"ขอทำข้อนี้ครับ/ค่ะ"** เพื่อไม่ให้ทำซ้ำกับคนอื่น

## ขั้นที่ 3 · แก้ไฟล์บนเว็บ GitHub

ตัวอย่าง: **เพิ่มบทเรียนหมูควาย**

1. เปิดไฟล์บทเรียน:
   https://github.com/kawinthorn11-collab/english-scholarship-trainer/blob/main/src/data/duoLessons.js
2. กดไอคอน **ดินสอ ✏️** (Edit this file) มุมขวาบนของไฟล์
3. GitHub จะถามว่าจะ **Fork this repository** ไหม → กดปุ่มสีเขียวยืนยัน
   (คือการทำสำเนาไว้ในบัญชีคุณ ไม่กระทบของจริง)
4. เลื่อนลงไปหาบรรทัด `export function getDuoLesson` แล้ววางบทเรียนใหม่ **ไว้ก่อนบรรทัด `]`** ที่อยู่เหนือบรรทัดนั้น
   คัดลอกแบบฟอร์มนี้ไปแก้:

```js
  {
    id: 'ชื่อภาษาอังกฤษสั้นๆ-ไม่ซ้ำ',
    emoji: '🅰️',
    title: 'หัวข้อภาษาอังกฤษ',
    titleThai: 'คำอธิบายสั้นๆ ภาษาไทย',
    color: 'from-sky-400 to-pink-500',
    lines: [
      { who: 'pig', text: 'หมูพูดประโยคแรก (สั้นๆ)' },
      { who: 'buffalo', text: 'ควายอธิบาย', example: 'English example sentence.' },
      { who: 'pig', text: 'หมูสรุป' },
    ],
    quiz: {
      question: 'คำถามท้ายบท ___',
      choices: ['ช้อยส์ 1', 'ช้อยส์ 2', 'ช้อยส์ 3', 'ช้อยส์ 4'],
      answer: 'ช้อยส์ที่ถูก (พิมพ์ให้ตรงทุกตัวอักษร)',
      explain: 'ทำไมข้อนี้ถูก',
    },
  },
```

**ข้อควรระวัง**
- เครื่องหมาย `'` `,` `{` `}` ต้องครบเหมือนตัวอย่าง (ผิดนิดเดียวเว็บจะพัง แต่ผู้ดูแลจะช่วยตรวจก่อนนำขึ้นเว็บ)
- `who` ใช้ได้แค่ `'pig'` หรือ `'buffalo'`
- แต่ละประโยคสั้น ๆ เพราะตัวการ์ตูนจะพูดออกเสียง
- ถ้าในข้อความมีเครื่องหมาย `'` ให้เปลี่ยนไปใช้ `’` แทน

## ขั้นที่ 4 · ส่งงาน (Pull Request)

1. กดปุ่มสีเขียว **Commit changes...** (หรือ Propose changes)
2. ช่อง Commit message เขียนสั้น ๆ เช่น `เพิ่มบทเรียนหมูควายเรื่อง a/an/the`
3. กด **Propose changes**
4. หน้าถัดไปกด **Create pull request** อีกครั้ง
5. ในช่องคำอธิบาย ใส่ `Closes #เลขIssue` (เช่น `Closes #2`) แล้วกด **Create pull request**

เสร็จแล้ว! ผู้ดูแลจะตรวจ อาจคอมเมนต์ขอแก้นิดหน่อย แล้วกด Merge นำขึ้นเว็บ
